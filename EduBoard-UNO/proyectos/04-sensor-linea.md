# Proyecto 4 — Detectar una línea ⬛

## Objetivo

Utilizar un sensor de línea para controlar un LED.

## Idea del programa

Repite continuamente:

- si el sensor detecta NEGRO → enciende LED1;
- si no → apaga LED1.

## Prueba

Acerca el sensor a una superficie clara y después a una línea oscura.

Observa cómo cambia el LED.

## Experimenta

Prueba con otro sensor o utiliza LED2.
