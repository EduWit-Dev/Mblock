# Conectar EduBoard UNO 🔌

## 1. Abre mBlock

Inicia mBlock en tu computadora.

## 2. Agrega un dispositivo

Busca la opción para **Agregar dispositivo**.

Después busca:

**EduBoard UNO**

y agrégala a tu proyecto.

> Aquí puedes colocar una captura de pantalla mostrando dónde aparece EduBoard UNO.

## 3. Conecta el cable USB

Conecta tu Arduino UNO + EduBoard UNO a la computadora.

## 4. Selecciona el puerto

Presiona **Conectar** y selecciona el puerto correspondiente a tu tarjeta.

Cuando aparezca conectada, ya puedes programar.

## Si no aparece el puerto

- Revisa que el cable USB esté bien conectado.
- Prueba desconectar y volver a conectar.
- Cierra y abre nuevamente mBlock.
- Prueba otro puerto USB de tu computadora.
