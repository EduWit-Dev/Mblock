# Comenzar 🚀

No necesitas experiencia previa.

## Necesitas

- Una **EduBoard UNO**.
- Una tarjeta **Arduino UNO compatible**.
- Un cable USB.
- Una computadora con **mBlock**.
- Muchas ganas de experimentar. 😄

## Antes de programar

1. Coloca tu EduBoard UNO sobre el Arduino UNO.
2. Conecta el cable USB a la computadora.
3. Abre mBlock.
4. Agrega el dispositivo **EduBoard UNO**.
5. Selecciona el puerto de tu tarjeta.

Cuando mBlock muestre que la tarjeta está conectada, puedes comenzar.
