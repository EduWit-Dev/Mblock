# Comunicación 🟣

La categoría Comunicación se utiliza en **Modo Cargar**.

Permite que tu proyecto envíe o reciba información.

## Puedes utilizarla para

- enviar mensajes;
- recibir comandos;
- trabajar con comunicación Serial;
- trabajar con proyectos Bluetooth.

## Ejemplo de idea

Puedes hacer que un comando recibido:

- encienda un LED;
- apague un LED;
- mueva un motor;
- active otra acción.

> Si estás comenzando, primero practica Eventos, Movimiento, Luz y sonido y Sensores. Después vuelve a esta categoría.
