# Luz y sonido 🟠

Usa esta categoría para crear señales con LEDs y sonidos.

## LEDs

Puedes controlar:

- LED1;
- LED2;
- LED3.

Ejemplo:

**ENCIENDE LED1**

También puedes encender o apagar un LED durante un tiempo.

## Sonidos

Puedes:

- tocar notas;
- tocar un tono;
- mantener un tono;
- detener el sonido.

## Reto

Crea una señal de inicio:

1. enciende LED1;
2. toca un sonido;
3. espera;
4. apaga LED1.
